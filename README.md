# Product Strategy Threat Analyzer

AI-powered strategic threat analysis tool for product managers and strategy teams.

## Features

- Strategic threat scoring
- Competitive pressure analysis
- Executive summaries
- AI-generated strategic recommendations
- Failure mode analysis
- Second-order effects analysis
- Strategic bets and product recommendations
- Leadership discussion prompts
- 90-day action planning
- Downloadable strategy reports
